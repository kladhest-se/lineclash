What you get

Everything. Nothing missing.

Full-featured multiplayer with the depth of modern guideline play and the chaos of specials.

⚡

Real-time multiplayer

Up to 8 players per room. Spectator mode. Team play. Dedicated server with reconnect window.

🎯

Guideline gameplay

SRS wall kicks, hold piece, lock delay, back-to-back bonus, combos, perfect clear. Fully configurable per room.

🤖

AI bots

Configurable difficulty. Bots use all game rules — garbage targeting, B2B, combos, all 10 specials.

💾

Persistent rooms

Room settings saved to SQLite and restored on restart. Leaderboard. Stats HTTP API.

🎮

GUI + terminal clients

SDL2 GUI client with HiDPI support. Terminal CLI client for headless or SSH play.

🖥️

Self-hosted

Run your own server. Packages for macOS, openSUSE Leap, Ubuntu. GPL-3.0 licensed.

Get started

Build from source.

No dependencies beyond a C compiler and SDL2. Compiles in seconds.

# Install SDL2
brew install sdl2

# Clone and build
git clone git@github.com:kladhest-se/lineclash.git
cd lineclash && make

# Run
./server/lineclashd &
./clients/gui/lineclash
# Install dependencies
sudo zypper install -y gcc make libSDL2-devel sqlite3-devel
