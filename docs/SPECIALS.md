# Specials

Clear lines to earn specials when the room enables them. The inventory is ordered: using an item consumes the next available special. Number keys target the displayed player IDs; targeting yourself can be useful for defensive items.

| Key | Special | Effect |
| --- | --- | --- |
| a | Add Line | Adds garbage to the target field |
| c | Clear Line | Removes the bottom line |
| b | Clear Specials | Clears the target’s special inventory |
| r | Random Clear | Removes randomly selected blocks |
| o | Block Bomb | Clears blocks around a blast |
| q | Quake | Shifts rows sideways |
| g | Gravity | Pulls settled blocks downward |
| s | Switch Field | Exchanges settled boards with the target |
| n | Nuke | Clears the target field |
| i | Immunity | Temporarily protects against incoming specials |
| v | Clear Column | Clears a column |
| m | Mutate | Changes the active piece |
| d | Darkness | Temporarily obscures the target field |
| f | Confusion | Temporarily reverses movement and rotation controls |

Effects depend on room rules and server implementation. In server-processed rounds, the server validates targets and inventory and applies board changes; clients cannot invent specials or award themselves clears. Turning attacks off disables special use.
